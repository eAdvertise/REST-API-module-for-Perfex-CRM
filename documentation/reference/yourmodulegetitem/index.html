GET /your-module/items/{id}

Get a module item

Returns one custom-module record by identifier.

RequestResponses operationId: yourModuleGetItem
01

Authentication

This endpoint requires an API token.

Request headerauthtoken: YOUR_API_TOKEN
02

Request

Path, query and body values accepted by this operation.

Parameters

idrequired
integerpath

Numeric item identifier.

Example42
03

Responses

HTTP outcomes documented for this operation.

200 Item returned successfully.

  "status": true,
  "data": {
    "id": 42,
    "name": "Customer onboarding",

    "updated_at": "2026-08-06T12:00:00Z"

cURL
curl -X GET "https://crm.example.com/api/your-module/items/42" \
