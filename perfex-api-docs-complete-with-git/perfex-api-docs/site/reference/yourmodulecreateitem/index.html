API Reference/Your Module
POST /your-module/items

Create a module item

Creates a new custom-module record and returns the stored resource.

RequestResponses operationId: yourModuleCreateItem
01

Authentication

This endpoint requires an API token.

Request headerauthtoken: YOUR_API_TOKEN
02

Request

Path, query and body values accepted by this operation.

Request body

application/jsonrequired
FieldTypeDescription
namestringHuman-readable item name.
descriptionstringOptional long description.
activebooleanWhether the item is currently active.
Example payload application/json 
{
  "name": "Customer onboarding",
  "description": "Initial onboarding workflow",
  "active": true
}
03

Responses

HTTP outcomes documented for this operation.

201 Item created successfully.

  "status": true,
  "data": {
    "id": 42,

  }

Example request
cURL
curl -X POST "https://crm.example.com/api/your-module/items" \
  -H "authtoken: YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Customer onboarding", "description": "Initial onboarding workflow", "active": true}'

Replace the base URL and token before running the request.
