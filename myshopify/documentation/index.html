MyShopify 2.0

Shopify ↔ Perfex CRM synchronization

A practical guide to the two-way customer, product, category and inventory integration, plus automatic Perfex invoice creation for paid Shopify orders.

Use staging first. Synchronization writes to both systems. Back up the Perfex database and start with test products, customers and orders.

Architecture

How data moves

ShopifyWebhooks + Admin API
⇄
MyShopify 2.0Mappings, timestamps, locks
⇄
Perfex CRMClients, items, groups, invoices
⇄
WarehouseSKU-linked inventory

Webhooks provide immediate Shopify-to-Perfex updates. Perfex hooks push local changes back to Shopify. The normal Perfex cron reconciles missed events.

Installation & Setup

Configure the Shopify custom app

  1. Create or open a Shopify custom app.
  2. Grant read/write access for customers, products, inventory, orders and collections.
  3. Install the app and copy its Admin API access token.
  4. Copy the webhook signing secret.
  5. Find the numeric Shopify inventory location ID.
SKU requirement: every variant to be synchronized must have a unique, non-empty SKU.

Run the initial synchronization

ADMINSetup → Settings → Integrations → MyShopify → Synchronize Shopify now

The action registers missing webhooks, pulls Shopify products, customers, orders and collections, then pushes Perfex item groups to Shopify. Keep the normal Perfex cron enabled afterward.

Synchronization Rules

Customers

Identity

Normalized, case-insensitive email address.

Conflict policy

The newest timestamp wins. Perfex wins equal timestamps.

Shopify → Perfex

Creates or updates the Perfex client and primary contact.

Perfex → Shopify

Customer updates push contact and billing details to Shopify.

A customer without an email cannot be synchronized.

Products and variants

KEYShopify variant SKU = Perfex item commodity_code
  • Each Shopify variant becomes a Perfex item.
  • Title, variant title, description, price and barcode are synchronized.
  • Variants without an SKU are skipped.
  • Duplicate SKUs are logged as errors instead of being linked ambiguously.
  • A mapped Perfex item update changes the Shopify variant; an unmapped Perfex item with an SKU can create a Shopify product.

Categories

Shopify custom/smart collections are mapped to Perfex item groups. Perfex item groups can be created or updated as Shopify custom collections during reconciliation.

Warehouse inventory

Inventory synchronization is enabled only when the Perfex warehouse module is active and its inventory table exists.

DirectionTriggerResult
Shopify → Warehouseinventory_levels/updateUpdates the mapped item quantity in the configured Warehouse.
Warehouse → ShopifyApproved goods receipt or deliverySends available stock to the configured Shopify location.

Paid orders and Perfex invoices

RULEInvoice creation requires financial_status = paid
  1. Lock the Shopify order ID to prevent concurrent processing.
  2. Find or create the Perfex customer by email.
  3. Map line items to Perfex items by SKU.
  4. Create the Perfex invoice using Shopify quantities, prices, totals and discounts.
  5. Save the Shopify order ↔ Perfex invoice mapping.

Unpaid orders are recorded but do not create invoices. Repeated webhooks or manual syncs return the existing invoice mapping, preventing duplicates.

Automation

Signed webhooks

POST/myshopify/webhook

The endpoint verifies X-Shopify-Hmac-Sha256 against the raw request body. Missing or invalid signatures receive HTTP 401.

Registered topics

customers/createcustomers/updateproducts/createproducts/updateorders/createorders/updatedorders/paidcollections/createcollections/updateinventory_levels/update

Cron reconciliation

Each normal Perfex cron run pulls records updated since the last successful sync, follows Shopify pagination links and repairs missed webhook events. A one-minute overlap reduces timestamp-boundary gaps.

Operations

Safe end-to-end test plan

  1. Customer: create shopify-test@example.com in Shopify and verify a Perfex client/contact appears.
  2. Product: create a variant with SKU SYNC-TEST-001, price 10 and stock 5; verify the Perfex item and Warehouse quantity.
  3. Reverse product: change its rate in Perfex and verify the Shopify variant price.
  4. Inventory: approve a Warehouse receipt and verify stock at the configured Shopify location.
  5. Unpaid order: create one and confirm no Perfex invoice exists.
  6. Paid order: mark it paid and confirm exactly one invoice is created.
  7. Idempotency: resend/update the same order and run manual sync; confirm no second invoice.

Troubleshooting

SymptomCheck
Manual sync failsVerify URL, token, API version and Shopify scopes; inspect Perfex application logs.
Product is missingEnsure every variant has a unique SKU and inspect myshopify_sync_log.
Stock does not moveVerify Warehouse is active and both location IDs are configured.
Webhook returns 401Webhook secret or HMAC signature does not match.
Paid order has no invoiceCheck customer email, line items and myshopify_order_map.last_error.
Duplicate invoice concernCheck the unique order mapping; processing also uses a database lock.

Useful SQL

SELECT * FROM tblmyshopify_sync_log ORDER BY id DESC LIMIT 100;
SELECT * FROM tblmyshopify_order_map WHERE last_error IS NOT NULL;
SELECT * FROM tblmyshopify_product_map WHERE sku = 'SYNC-TEST-001';

Replace tbl with your Perfex database prefix.
